# Known limitations

- No authentication, database, multi-user isolation, or report history.
- WHOIS/DNS completeness varies by registry, resolver, and privacy settings.
- Shodan needs a key and has coverage/quota limits.
- Username matches are leads, not identity proof; public pages can change.
- XposedOrNot is rate-limited; a clean result is not proof of no exposure.
- Caches are temporary process-local snapshots, not monitoring.
- The project returns metadata only, never breach dumps or credentials.
